1. 게임 내에서 계정 삭제하기

몬스터 유치원에 로그인한 상태에서 게임 내 설정 화면을 통해 계정 삭제를 진행할 수 있습니다.

계정 삭제 방법

1. 몬스터 유치원을 실행하고 Google Play Games 계정으로 로그인합니다.
2. 게임 내 설정 메뉴를 엽니다.
3. '계정 삭제' 기능을 선택합니다.
4. 삭제 안내를 확인한 후 계정 삭제를 진행합니다.

계정 삭제가 완료되면 해당 계정에 연결된 게임 진행 데이터와 Firebase Authentication 사용자 계정이 삭제됩니다.

3. 계정 삭제 시 삭제되는 데이터

계정 삭제가 완료되면 개발자가 관리하는 다음 데이터가 삭제됩니다.

  • Firebase Authentication 사용자 계정
  • Firebase 사용자 식별자(UID)와 연결된 게임 진행 데이터
  • 보유 재화 정보
  • 슬라임 및 스테이지 진행 정보
  • 도감 및 플레이 기록
  • 업그레이드 정보
  • 기타 해당 계정에 연결된 게임 진행 데이터

4. 기기에 저장된 데이터

일부 게임 설정 및 게임 데이터는 사용자의 기기에도 저장될 수 있습니다.

계정 삭제 과정에서 계정과 연결된 게임 진행 데이터가 삭제되며, 앱을 삭제하면 해당 기기에 남아 있는 로컬 데이터도 삭제할 수 있습니다.

5. 데이터 보관

계정 삭제가 정상적으로 완료되면 개발자가 관리하는 Firebase Authentication 사용자 계정과 해당 계정에 연결된 게임 진행 데이터를 별도로 보관하지 않습니다.

단, Google Play Games 또는 Firebase 등 외부 서비스가 자체적으로 처리하는 데이터에는 각 서비스 제공자의 개인정보처리방침 및 데이터 보관 정책이 적용될 수 있습니다.

6. 계정을 유지하면서 게임 데이터만 삭제하기

계정을 삭제하지 않고 게임 진행 데이터만 초기화하려는 경우, 게임 내 '게임 데이터 초기화' 기능을 이용할 수 있습니다.

이 기능을 사용할 경우 게임 진행 데이터는 초기화되지만 Firebase Authentication 사용자 계정은 유지됩니다.
